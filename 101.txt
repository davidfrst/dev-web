1. Por que praticamente todo site hoje usa HTTPS?  
R: Hoje é interessante todo site ter criptografia por questões de segurança, então utilizamos o protocolo HTTPS.

2. O que aconteceria se navegadores não interpretassem HTML?  
R: Sim, veríamos o código-fonte puro, assim como vemos na aba elements ao apertar F12 (Chrome).

3. Qual a maior mudança da Web 1.0 para a Web 2.0?  
R: Na época do Web 1.0, as páginas WEB eram apenas para a visualização do usuário (estáticas). Ao evoluir para Web 2.0, o usuário além de visualizar as páginas agora podem inserir dados (dinâmicas).

4. Como a IA pode mudar o desenvolvimento web no futuro?  
R: Principalmente uma adaptabilidade ao usuário, como por exemplo, recomendações individuais. Também solução de problemas com chatbots, respostas adaptadas ao perfil do usuário, etc.
